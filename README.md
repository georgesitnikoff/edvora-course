# Edvora — производная и первообразная

Полный курс на русском: **49 уроков, 1213 этапов, 67 управляемых исследований**. В каждом уроке 20–30 этапов и три итоговых задания. Чтение графиков, средняя и мгновенная скорость, касательная, знаки производной, исследование функций, вычислительные правила, движение, первообразная и накопление.

Перед блоками курса — входная диагностика из 20 заданий с рекомендациями по конкретным урокам. 16 заданий взяты из официальных материалов ФИПИ 2023–2026 годов; четыре задания на первообразную явно подписаны как авторские. Ответы, пропуски и уверенность сохраняются; разборы доступны после завершения. Источники и методика — в [docs/DIAGNOSTIC.md](docs/DIAGNOSTIC.md).

В редакции 10 октября убраны формулы с карточек, исправлены русские формулировки и добавлены 46 объяснений и закрепляющих шагов при переходе к формулам. На телефоне исходные экзаменационные рисунки можно увеличить и прокрутить. Прежние сохранения и позиции продолжения совместимы.

Курьеры, резервуар и велосипедный маршрут возвращаются в следующих уроках с новыми вопросами. Формулы управляют сценой и графиком: положение, наклон, касательная, скорость и накопление согласованы. Ученик выбирает интервалы и точки на рисунке, настраивает параметры, вводит числа и дроби экранной клавиатурой. Можно собрать закон движения или отношение разностей из карточек; мышь, касание и клавиатура дают одинаковые возможности. После ответа доступно объяснение; после ошибок — подсказки и повторение. Итог урока отдельно показывает самостоятельные решения с первой попытки и предлагает разбор ошибок.

## Быстрый запуск

Нужен Node.js 24. Из папки проекта:

```bash
npm ci
npm run dev
```

Открой адрес, который напечатает Vite. Аккаунт и сервер данных не нужны. Для просмотра готовой сборки из архива:

```bash
npm ci
npm run preview
```

`dist/` содержит production-сборку для корня сайта. При изменении кода пересобери её командой `npm run build`. Открытие `dist/index.html` через `file://` не заменяет HTTP-сервер.

## Проверки

```bash
python3 -m pip install -r scripts/requirements-qa.txt
npm test
npm run lint
npm run validate:math
npm run build
npm run validate:pwa
```

В Windows команда Python обычно называется `python`. Можно выполнить `python scripts/independent_math_check.py` и `python scripts/independent_scene_check.py` и `python scripts/independent_diagnostic_check.py` после `npm test`.

`npm test` проверяет структуру всех 1213 этапов, цели исследований, графики, отображение формул и движок. Независимые проверки SymPy сверяют 479 вычислительных ответов, 13 ответов о сценах, интервалах и точках, а также 5 сборок формул. Подробные результаты и границы покрытия — в [docs/QA_REPORT.md](docs/QA_REPORT.md).

## Прогресс и офлайн

В «Мои данные» можно скачать резервную копию JSON и восстановить её на другом устройстве. Сохраняются ответы, попытки, подсказки, пройденные шаги, собранные формулы, положения ползунков и очередь повторения. Сохранения и ссылки из прежней версии с 24 длинными уроками автоматически перенаправляются к тем же заданиям в коротких уроках. Ошибки и помощь возвращают задания сразу; успешные самостоятельные повторения увеличивают интервал до 1, 3, 7, 14 и 30 дней.

В production-сборке весь курс и математические шрифты включены в офлайн-пакет. Дождись статуса «Весь курс сохранён для работы без сети» в «Мои данные» после первого открытия по HTTPS или на localhost. Режим разработки этот пакет не подключает. Обновление устанавливается целиком; неудачная загрузка не заменяет работающий пакет.

Прогресс хранится в браузере на текущем адресе сайта. Перед сменой адреса, браузера или очисткой данных скачай копию. При отказе локального сохранения курс сообщает об этом и сохраняет ответы в памяти текущей вкладки для экспорта.

## GitHub Pages

В проекте есть `.github/workflows/check.yml` и `.github/workflows/deploy-pages.yml`. Они проверяют курс и публикуют его в твоём репозитории после настройки Pages. Внешняя публикация в этой задаче не выполнялась.

1. Создай пустой репозиторий, распакуй проект и открой терминал в его папке.
2. Выполни команды, заменив адрес своим:

```bash
git init
git add .
git commit -m "Add Edvora derivative course"
git branch -M main
git remote add origin https://github.com/YOUR_LOGIN/edvora.git
git push -u origin main
```

3. В **Settings → Pages → Source** выбери **GitHub Actions**.
4. Запусти **Deploy Edvora to GitHub Pages** во вкладке **Actions**, если первый запуск произошёл до настройки Pages.

Workflow берёт базовый путь из настроек Pages. Проверена сборка для корня `/` и подпапки `/edvora-test/`.

Вручную собрать для подпапки:

```bash
VITE_BASE_PATH=/edvora/ npm run build
```

В PowerShell:

```powershell
$env:VITE_BASE_PATH = "/edvora/"
npm run build
Remove-Item Env:VITE_BASE_PATH
```

## Данные

Приложение не использует авторизацию, аналитику, внешнюю базу и запросы к модели. Сцены сделаны в SVG, графики вычисляются локально. Эффективность обучения требует отдельной проверки с учениками; техническая проверка не подменяет такой результат.
