# Edvora

Edvora — автономный мобильный тренажёр по теме «Производная» для профильной математики ЕГЭ. Урок построен как короткая последовательность: смысл → действие с графиком → типичная ловушка → самостоятельный ответ → обратная связь.

## Что входит в MVP

- 5 уроков и 40 шагов, включая 8 независимых заданий босс-файта;
- касательная, знак и значение производной, монотонность, экстремумы, максимум на отрезке и условие `f′(x) = k`;
- физический смысл производной через координату, скорость и ускорение;
- первообразная, формула Ньютона—Лейбница и ориентированная площадь как соседний концептуальный блок;
- локальное сохранение прогресса без аккаунта и сервера;
- PWA-режим, офлайн-кэш и интерфейс, рассчитанный на палец, а не на клавиатуру.

Методологические границы и сверка с ФИПИ описаны в [METHODOLOGY_AUDIT.md](./METHODOLOGY_AUDIT.md). Матрица проверки смартфонов — в [DEVICE_QA.md](./DEVICE_QA.md).

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Проверки и production-сборка:

```bash
npm test
npm run lint
npm run build
npm run preview
```

`npm test` проверяет структуру курса, варианты ответов, визуальное покрытие, численные инварианты задач, PWA-манифест и реальные размеры иконок. Production-файлы появляются в `dist/`.

## Установка на смартфон

### Android

1. Откройте опубликованный HTTPS-адрес в Chrome.
2. Нажмите меню ⋮ → «Установить приложение» или подтвердите появившееся предложение.
3. Запускайте Edvora с иконки на домашнем экране.

После первого успешного открытия оболочка и загруженные ресурсы остаются в кэше. Прогресс хранится только на этом устройстве в `localStorage`.

### iPhone / iPad

1. Откройте адрес именно в Safari.
2. Нажмите «Поделиться» → «На экран “Домой”» → «Добавить».
3. Запускайте Edvora с домашнего экрана: приложение откроется без обычной панели браузера.

## Публикация на GitHub Pages

В проект уже добавлен workflow `.github/workflows/deploy-pages.yml`. Он проверяет курс, собирает приложение с правильным адресом подпапки и публикует его после каждого `push` в ветку `main`.

1. На GitHub создайте **пустой публичный репозиторий**, например `edvora`. Не добавляйте README или `.gitignore` на сайте GitHub.
2. Откройте PowerShell в распакованной папке Edvora и выполните, заменив `ВАШ_ЛОГИН`:

```powershell
git init
git add .
git commit -m "Publish Edvora"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/edvora.git
git push -u origin main
```

3. На странице репозитория откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**.
4. Дождитесь зелёной галочки во вкладке **Actions**. Адрес будет вида `https://ВАШ_ЛОГИН.github.io/edvora/`.

После следующих изменений достаточно повторить:

```powershell
git add .
git commit -m "Update Edvora"
git push
```

PWA, офлайн-кэш и установка на домашний экран поддерживают публикацию как в корне домена, так и в подпапке GitHub Pages.

## Публикация на Vercel

Файл `vercel.json` уже настроен. Самый простой путь — сначала выгрузить проект на GitHub, затем на [Vercel](https://vercel.com/new) нажать **Import Git Repository → Deploy**. Vercel определит Vite автоматически; ожидаемые параметры: Build Command — `npm run build`, Output Directory — `dist`. Каждый следующий `push` будет создавать новое развёртывание.

Без GitHub можно установить Vercel CLI и из корня проекта выполнить `vercel --prod`, но для команды потребуется вход в ваш аккаунт Vercel.

## Как получить APK

Для пилота на Android рекомендуется сначала PWA: она устанавливается без файла APK и обновляется вместе с веб-версией. Если школе нужен именно APK, воспроизводимый путь — Capacitor:

```bash
npm install @capacitor/core @capacitor/android
npm install --save-dev @capacitor/cli
npx cap init Edvora app.edvora.trainer --web-dir dist
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

Далее в Android Studio выберите **Build → Generate Signed Bundle / APK**, создайте или подключите keystore и соберите release APK. Сам репозиторий не содержит подписанный APK: для него необходимы установленный Android SDK, Gradle/JDK и пользовательский ключ подписи. Ключ нельзя хранить в репозитории.

Альтернатива для опубликованной PWA — Trusted Web Activity через Bubblewrap/PWABuilder. Она дополнительно требует стабильного HTTPS-домена, Android SDK, подписи и файла Digital Asset Links на домене.

## Данные и приватность

У приложения нет авторизации, базы данных и аналитики. Состояние хранится в браузере пользователя. Очистка данных сайта удалит прогресс. Для полевого замера до/после результаты нужно фиксировать отдельно по протоколу исследования.
